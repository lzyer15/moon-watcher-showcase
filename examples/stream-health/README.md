# 오래된 시세가 계속 들어오면 어떻게 하나

실제 `TradeStreamHealth.swift`를 변경 없이 가져왔다. 연결이 열려 있다는 이유만으로 시세가 최신이라고 보지 않는다. 오래된 프레임이 10개 이상 들어오고 첫 관측 이후 15초가 지나면 재연결 필요를 반환한다. 신선한 프레임을 받으면 상태를 초기화한다.

```sh
cd examples/stream-health
swift run stream-health-demo
./test.sh
```

Swift 5.9 이상. 외부 패키지·브로커 연결·계정 설정이 필요 없다. 결과만 반환하는 예제이며 실제 재연결이나 주문을 실행하지 않는다.

| 입력 | 예상 동작 |
|---|---|
| 10초 오래된 프레임이 매초 지속 | 15초 시점에 재연결 필요 |
| 같은 순간에 오래된 프레임 100개 | 재연결하지 않음 |
| 드문 프레임 두 개만 들어오는 조용한 시장 | 재연결하지 않음 |

프로덕션 테스트 두 시나리오의 본문은 유지했다. XCTest 대신 작은 assertion 어댑터를 붙여 Xcode 없이 실행할 수 있게 했다. 이 예제는 시세 전송 상태를 다룬다. 개별 후보·급등 알림의 최종 판정은 별도 로직이다.
